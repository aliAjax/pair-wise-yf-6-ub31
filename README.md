# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用 localStorage 保存数据。

## 派工验收闭环

- **派工**：未完成事项填写施工人与报价后派工，事项转为「处理中」。每个未完成事项只允许一张进行中派工单，重复派工整次拒绝，原单不变。
- **验收**：必须交实付费用与验收照片；实付费用超出报价时还必须填写超支原因。缺任一项整次失败，事项与派工单保持原状态；验收成功后事项转为「已完成」。
- **取消**：进行中（未验收）的派工单可取消，事项恢复派工前状态，派工单作为历史单保留，之后可重新派工。已验收、已取消的历史单不可再操作。
- **统计**：顶部「预计费用」统计未完成事项——有进行中派工单的按派工报价计，其余按事项预计费用计；列表与状态筛选随闭环同步。
- 所有数据继续保存在浏览器 localStorage，旧版本数据会自动迁移（当前数据版本 v2：新增派工单列表与派工前状态字段）。

## 代码结构

规则、迁移、交互分别维护，不依赖任何第三方运行库：

- `src/rules.js`：派工 / 验收 / 取消的纯函数规则，写操作整次成功或整次失败，返回 `{ ok, data|error }`。
- `src/migration.js`：localStorage 读写与版本迁移。
- `src/main.js`：渲染、事件与交互，只负责调用规则层并落地结果。
