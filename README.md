# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第二版闭环：记录维修问题、按状态查看、派工与验收、取消派工、统计未完成预计费用，支持照片链接并使用 localStorage 保存数据。

## 业务闭环

- **派工**：未完成事项才能派工，且每张事项至多一张进行中派工单；重复派工整次拒绝、原单不变。派工须填施工人与报价，成功后事项转为「处理中」。
- **验收**：须交实付费用与验收照片；实付超过报价时超支原因必填。缺任一项整次失败，事项与派工单保持原状态。验收成功后事项转为「已完成」。
- **取消**：只能取消未验收的进行中派工单；取消后事项恢复派工前状态，派工单转入历史保留，之后可重新派工。
- **统计**：未完成事项中，已派工按派工报价、未派工按预估费用计入预计费用；列表筛选与统计同步。

## 代码结构（规则 / 迁移 / 交互分离）

- `src/rules.js`：派工、验收、取消、统计的纯业务规则，不依赖 DOM 与存储。
- `src/migrate.js`：localStorage 版本与数据迁移（v1 本地数据自动升级到 v2，旧数据保留）。
- `src/main.js`：界面渲染、表单与事件交互。
- `src/styles.css`：样式。

无新增依赖。
